# Notes for the native-speaker reviewers

Points the content authors were unsure about. Check them together with `CONTENT_REVIEW.md`.

## cs-en (English)
- Strict review of A1 (units 1–10) done: author doubts resolved (Unit 1 glosses, „Jmenuji se“, all Czech
  pronunciation hints checked against British IPA — only Tuesday changed to „tjúz-dej“). Open points:
- Articles: "the" is used from U2 but explained only in one sentence (u4-l1 tip); no lesson drills a/the contrast.
- Untaught words in exercises: "in", "number", 40–90 (U2–U3), "me" (u8-l3 tip), "very" (u10-l3-e5), "every week" (u10-l3-e2 option).
- "A tea, please." / "I'd like a tea and a sandwich" — normal café English, but check you are happy not using "a cup of tea".
- Neutral Czech via plural vykání („Co máte rádi?“, „Kde jste byli…?“); learner's own 1st-person lines mix genders
  („Včera jsem byla unavená.“, „Narodil jsem se…“, „Minulý týden jsem byl nemocný.“) — acceptable?
- Syllabus: numbers split 1–9 (U2) / 10–100 (U3); months split in U12; wh-words listed as words only in U11.

## cs-de (German)
- Pronunciation hints in Czech spelling are approximate (Wiedersehen now „VÍ-da-zé-en“; vocalised r written „a“, e.g. Vater „fáta“, Fieber „FÍ-ba“).
- Tschüss = „čau; nashle“, Hallo = „ahoj“ (kept distinct for tests).
- „Guten Morgen“: note says until about 10 a.m. (regional).
- Syllabus: „null“ only in U19, „hundert“ in U17, months with articles (der Januar).

## cs-ro (Romanian)
- Strict review of A1 (units 1–10) done. All hints now one style, „Čte se …“ in Czech spelling (â/î written „y“,
  ă kept), checked against Wiktionary IPA. Still worth listening to: ă ≈ „ehm“, î ≈ Russian ы, „PRJE-ten“
  (everyday [ˈprje.ten]; prescribed [priˈe.ten]), „FIJ-kă“, „drept y-na-IN-te“, „kyt je časul“, „luň“.

### cs-en units 8–10
- Days in habit sentences avoided ("on Mondays" vs "on Monday") — "on Mondays" not taught in A1.

### cs-de units 5–7
- Time: only Viertel nach/vor, halb (halb drei = půl třetí); regional "viertel drei" not taught.
- Accepted alternatives: u5-l1-e8 "Wie viel Uhr ist es?", u5-l3-e7 "Um sechs Uhr stehe ich am Montag auf."
- Meanings: nach = „po“, vor = „před“, um = „v (u hodin)“, anrufen = „telefonovat; zavolat“.
- "mit dem/der" taught as fixed phrases before the Dativ (unit 11).
- Directions kept as "Gehen Sie an der Ecke links / an der Ampel rechts" (A1 textbook style; "Biegen Sie … ab" / "nach links" not taught) — native check welcome.
- Pronunciation hints: Viertel [firtl], Dienstag [dínsták], Zug [cúk], ö explanation. kalt = „studený; chladný“.

### cs-en units 2–4
- u2-l3 tip: 0 read as „ou“ (zero / "double seven" not mentioned) — enough for A1?

### cs-en units 5–7
- Time flashcards: half past = „půl“, quarter past = „čtvrt na“, quarter to = „tři čtvrtě na“ — on a card alone the
  hour shift is only in the note (half past two = půl třetí). Better gloss?
- I'd like = „chtěl bych; chtěla bych“ (two genders on one card); exercises use neutral „Prosím si…“.

### cs-de units 2–4
- das Brötchen = „houska“ (not „rohlík“); ich möchte = „chtěl bych; chtěla bych“, exercises use „Dám si …“.
- Kaffee [kafe] (north) vs [kaˈfeː] (south); plurals die Frühstücke, die Käse, die Wasser, die Kilos vs zwei Kilo.
- zum Frühstück, mit Milch used before being taught; "Die Möbel" title word not taught.

### cs-ro units 8–10
- „în numerar“ = „hotově“ (note mentions colloquial „cash“) — or should „cash“ be the main form?
- pantofii = „boty“ (note: strictly polobotky), taught in definite plural like pantalonii.
- Past-tense word cards now „pracoval jsem; pracovala jsem“; sentences in tips/options still use „pracoval(a)“.
- în vacanță = „na prázdninách“ vs un concediu = „dovolená“; u10-l2-e9 translates „în vacanță“ as „na dovolené“.
- Untaught words in U10 exercises: un film, o carte (tip), o zi (option).

### cs-ro units 2–4
- Mă cheamă = „říkají mi“ (to keep it distinct from Mă numesc = „jmenuji se“).
- un leu / un ban now „rumunský lei“ / „ban; haléř“ — happy with these Czech names?
- paisprezece/șaisprezece, fac („Unsprezece și nouă fac douăzeci“), treisprezece, am/are, șaizeci used before being taught.

### cs-ro units 5–7
- Uncountables are now taught bare with a „niște …“ note: lapte, unt, zahăr, smântână, slănină (and timp in U10); o brânză kept with „o“.
- u7-l2-e7: „Sâmbătă merg la piață“ is grammatical (= this Saturday); only the Czech „Každou sobotu“ makes Sâmbăta the answer.
- Mergeți la dreapta (also „o luați la dreapta“); Merg în oraș = „jedu do města“.
- Meanings: ciorbă = „kyselá polévka“, a se trezi = „budit se; probouzet se“; orders translated „Dám si…“.

### cs-de units 8–10
- "Ich nehme ihn/sie/es" used in u8-l2 before nehmen is taught (u9-l3; the u8-l2 tip glosses nehmen = vzít); "suchen" not in the syllabus (explained in the u8-l1 tip).
- Untaught words still in exercises/tips: beim Arzt, ans Meer, unsere, Prag, zum Geburtstag, Frohe Weihnachten/Ostern, Guten Appetit, nicht so gut; adjective endings (einen großen Bauch, gute Zähne, blaue Augen, ein schönes Fest) appear before A2.
- Meanings: der Termin = „objednání; schůzka“, der Arm = „paže“, laufen = „běžet“, die Schmerzen = „bolesti“, war = „byl; byla“, hatte = „měl; měla“, „Ich habe eine Erkältung“ = „Mám nachlazení“.
- Hints: teuer [TOJ-a], täglich [TÉK-lich], Fieber [FÍ-ba], Pullover [pu-LÓ-va], Geburtstag [ge-BÚRC-ták], Erkältung [er-KEL-tung].
- u10-l1 tip: „wir haben gekocht“ ≈ „máme vařeno“ (memory hook).
